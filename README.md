# Carey

Carey es una isla dinámica y una pantalla de bloqueo para Windows. Está en **beta** (versión 1.0 beta 1).

- Página: https://Cain-webg.github.io/carey/
- Descargas: https://github.com/Cain-webg/carey/releases
- Problemas y sugerencias: https://github.com/Cain-webg/carey/issues

Requisitos: Windows 10 2004 o posterior, o Windows 11, de 64 bits, con Microsoft Edge WebView2 Runtime.

Descarga `Carey-1.0.0-beta.1-win-x64.zip` desde Releases, descomprímelo y abre `Carey.exe`. Huella SHA-256 del ZIP: `C07A4859ACD1986007F243060017A0FB6FA5F92C66FD32F44DA60ECF224D3091`.
